# Anup Jewellers 🪙💍

A responsive and user-friendly website built for a jewellery business to showcase collections, engage customers, and establish an online presence.

## 🔗 Live Demo

https://fabulous-bubblegum-6db57c.netlify.app/

## 📌 Features

- Beautiful homepage layout with elegant design  
- Navigation bar with quick access to different sections  
- Product showcase with jewellery categories  
- Responsive design for mobile and desktop  
- Contact section for business inquiries  

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Frameworks/Libraries:** None (Vanilla)  
- **Tools:** VS Code, Git, GitHub
